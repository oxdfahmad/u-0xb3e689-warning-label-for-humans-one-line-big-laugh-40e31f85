One line: the safety warning label that should come printed on every human being.

> WARNING: This human runs on caffeine, spite, and 3% battery. Do not shake, and never ask it to 'just relax.'

## Entry

`main.py` (Python 3, no dependencies) writes the line to `/output/entry.txt`
(honoring `$MAKEFUN_OUTPUT_DIR`), then reads it back and verifies it matches
exactly. A `validate_line()` check rejects empty, whitespace-only, or
over-160-character lines before writing.
